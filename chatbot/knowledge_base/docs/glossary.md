# Glossary

- DUN: Dewan Undangan Negeri, the state assembly. Each seat is a DUN seat.
- PH / Harapan: Pakatan Harapan, the target group of the model.
- BN: Barisan Nasional. PN: Perikatan Nasional. Counted together as BN/PN.
- OOD: out of distribution. The seat looks unlike the training data.
- Fallback: blending with the seat's historical base rate when a seat is OOD.
- Base rate: how often the opposition won a seat in earlier elections.
- Flip: a seat that changed winning side from the previous election.
- Frozen forecast: a forecast saved with a checksum before the election.
- Validated: scored against the real result of an election that has happened.
- AUC: how well the probabilities rank seats, ignoring the cut-off.
- Persistence baseline: the rule "same result as the previous election".
